### [forecast-calibration-kit](https://github.com/donizetiferr/forecast-calibration-kit)

Zero-dependency TypeScript toolkit for evaluating probabilistic forecasts with **Brier score, log loss, ECE, calibration curves, and Murphy decomposition**.

- Fully typed API for both ESM and CommonJS.
- CLI for scoring JSON datasets directly from the terminal.
- 98% test coverage and a package published on npm.
